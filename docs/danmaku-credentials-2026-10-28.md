# Kazumi SR 弹幕凭证配置（2026-10-28）

## 已实现

- 设置 → 弹幕设置 → 弹弹play凭证：填写 App ID / App Secret，验证连接、保存或清除自定义凭证，并可打开官方开发者中心。
- 自定义凭证优先；未配置自定义凭证时使用官方构建时注入的凭证。草稿验证不保存、不切换当前配置，保存后下次请求立即生效。
- Windows 使用系统凭据管理器中的独立通用凭据 `KazumiSR/dandanplay/v1`。App ID 和密钥作为同一个条目原子更新，不写入 Hive、设置导出文件、同步数据或便携包。密钥输入默认隐藏。
- 其他平台保留编译注入凭证的路径；暂未实现其他平台的自定义安全存储。
- 检索、番剧映射、分集与弹幕下载共用凭证解析和签名。未配置凭证时在发起网络请求前报错。
- 手动检索与自动加载显示具体错误：凭证缺失/无效、签名错误、系统时间错误、超时、限流、业务失败或异常响应；成功但无结果单独显示。
- 检索失败页面提供配置入口；手动切换弹幕源请求失败时保留原有弹幕数据。
- 超分处理逻辑未修改。

## 使用与验收边界

在官方开发者中心 `https://dev.dandanplay.com/` 申请并取得有效应用凭证，然后填写、验证连接并保存。不要把密钥粘贴到聊天或日志中。

当前没有有效应用凭证，因此尚未验证真实的成功检索、分集选择和播放器弹幕显示。配置功能、错误处理、安全存储、构建和界面已经验证，不代表在线弹幕功能已恢复。凭证保存在 Windows 用户侧，复制便携目录到其他用户或机器时需要重新配置。
