# 可调超分倍率

设置入口：设置 → 播放设置 → 超分辨率 → 默认处理倍率。
播放时：超分辨率菜单 → 处理倍率。播放菜单只调整当前播放器会话；
换集、切源或重建播放器时沿用当前会话选择。新播放器会话读取默认值。
关闭超分时倍率不执行，重新开启后使用当前选定倍率。

## 行为

- 自动：保留原有着色器顺序和基于显示尺寸的执行条件。
- 1.5×：原尺寸修复 → x2 CNN → 缩小到原始宽高的 1.5 倍。
- 2×：原尺寸修复 → x2 CNN。
- 3×：原尺寸修复 → x2 CNN → x2 CNN → 缩小到原始宽高的 3 倍。
- 4×：原尺寸修复 → x2 CNN → x2 CNN。

倍率指内部处理尺寸；最终显示仍适配原有播放器区域和画面比例。
固定模式在小窗口下也会执行指定 CNN 阶段。3× 的计算开销接近 4×。
质量档位和倍率独立，较高倍率不保证画质更好。

固定模型变体在启动时从内置 Anime4K 资产生成，只移除视口相关的
`//!WHEN` 条件，不改 CNN 权重或固定 x2 的 Depth-to-Space 运算。
原始资产保持原样。生成的模型和缩放着色器位于应用支持目录的
`anime_shaders_v2`，原始资产按内容更新，生成文件在启动时刷新。
小数倍率通过最后一个 MAIN 阶段以 NATIVE 尺寸为基准重采样，
使用纹理采样器插值，不代表训练了原生 1.5× 或 3× 模型。

超分命令串行执行，过期播放器请求丢弃；缺少资源或命令失败时尝试恢复
上一组设置并提示。MediaCodec 嵌入渲染器不支持此功能。
mpv 接受着色器列表不等于 GPU 成功编译和运行，仍需实际播放验证。

## 构建环境与修复

Flutter 3.47.7 / Dart 3.13.5；Visual Studio Build Tools 2022 17.14.42。
构建工具主目录在工作区 `.vs`；Flutter、下载缓存和依赖快照在仓库 `.cache`。
没有修改系统代理或开发者模式，插件使用工作区目录联接。

GitHub 直连不可用，五个 Git 依赖从 GitHub 连接器读取固定提交，逐文件
核验 Git blob 哈希，使用本机 pubspec_overrides.yaml 指向快照。
libmpv 与 ech_http SDK 从对应 GitHub Actions 构建产物取得，发布压缩包
SHA-256 与依赖源码内置值完全一致。依赖解析结果保存在 pubspec.lock；
本机覆盖配置和快照仅用于本次环境，不包含在便携运行目录中。

另修复 ech_http 0.2.2 的 MSVC C2026：CA 证书大字符串改为字节数组，
启用 /utf-8。生成数组与原始 cacert.pem 的188900字节逐字节相同。
补丁保存在 ech-http-msvc.patch。该补丁仅应用于本机依赖副本。
